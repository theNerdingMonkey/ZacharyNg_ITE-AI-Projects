Timeline Layout in CSS

.timeline {
    position: relative;
    max-width: 1000px;
    margin: 0 auto;
    padding: 3rem 0;
}

.timeline::before {
    content: '';
    position: absolute;
    left: 50%;
    transform: translateX(-50%);
    top: 0;
    bottom: 0;
    width: 4px;
    background: linear-gradient(to bottom, #667eea, #764ba2);
    border-radius: 2px;
}

.timeline-item {
    position: relative;
    margin-bottom: 4rem;
    width: 100%;
    display: flex;
    align-items: center;
}

.timeline-item:nth-child(odd) {
    justify-content: flex-start;
    padding-right: 50%;
}

.timeline-item:nth-child(even) {
    justify-content: flex-end;
    padding-left: 50%;
}

Purpose: To show milestones as documentation of our learning from this project.

Rationale: By putting timeline in a chronological order, provides a clear overview of our learning.

What I've learnt:
  • CSS timeline can create informative chronological displays
  • Alternate left and right of timeline items using :nth-child() selectors

CSS Flexbox Layout

.projects-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(350px, 1fr));
    gap: 2.5rem;
    margin-bottom: 2rem;
}

.project-card {
    background: white;
    border-radius: 15px;
    overflow: hidden;
    box-shadow: 0 5px 20px rgba(0,0,0,0.08);
    transition: all 0.3s ease;
    border: 1px solid #e9ecef;
}

Purpose: To create responsive grid layout for project cards.

Rationale: By using Flexbox wisely, provides flexible alignment and distribution.

What I've learnt:
  • CSS Flexbox is a layout model that helps designing flexible and responsive layout structures without using float or positioning.
  • Flexbox is supported by all modern browsers, making alignment in complex layout possible.

Universal/Global Selector (*)

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

Purpose: Ensure all elements of the site being styled globally within a specific context.

Rationale: By having global selector or targeting to descendant of an element, standard of layout of site is cleaner and easy for debugging.

What I've learnt:
  • Universal Selector (*) selects all elements of any type
  • It can also select all elements inside another element
  • Selectors can be used with namespace (ns)
    • ns|* - selects all elements declared in namespace
    • *|* - selects all elements
    • |* - selects all elements without namespace declared.
  • Using global selectors styles makes bug-fixing easier.

Responsive Navigation

@media (max-width: 768px) {
    .nav-container {
        padding: 0 1rem;
    }
    
    .nav-menu {
        flex-direction: column;
        gap: 0;
    }
    
    .nav-link {
        padding: 1rem 1.5rem;
        width: 100%;
        text-align: center;
        border-bottom: 1px solid rgba(255, 255, 255, 0.1);
    }
}

    @media (max-width: 480px) {
    .hero {
        padding: 2rem 1rem;
    }
    
    .hero h1 {
        font-size: 1.8rem;
    }
}

Purpose: To display and provide appropriate content layout and navigation tool for different devices' screen size.

Rationale: By catering different devices' screen size, makes user have a better online experience.

What I've learnt:
  • Media Queries is a effective technique to deliver a tailored stylesheet to different devices
  • Media Queries can varied different layouts with different number of columns for different viewports, looking for the max-width.
  • Specifying different screen sizes and navigation habits, improve loading time of contents navigations throughout the site.

CSS Hover Pseudo Class

.btn:hover {
    transform: translateY(-3px);
    box-shadow: 0 6px 20px rgba(102, 126, 234, 0.4);
}

.project-card:hover {
    transform: translateY(-8px);
    box-shadow: 0 12px 30px rgba(0,0,0,0.15);
}

.footer-nav a:hover {
    background-color: rgba(255, 255, 255, 0.1);
    text-decoration: none;
}

Purpose: To provide user with a feedback after each interaction.

Rationale: By giving visual feedback to keep user informed, improve user engagement to the site.

What I've learnt:
  • The :hover pseudo class must come after :link and :visited in order to work.
  • :hover pseudo class can apply to all elements, not only on links.
  • With :hover pseudo class, using visual cues at appropriate moments, improves user experience.
